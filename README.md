# たびのあと — 都道府県カウンター

日程・都道府県・来訪理由を記録し、日本地図で **得点 / 来訪回数** を切り替えて確認できるWebアプリです。スマートフォンとPCに対応しています。

## 使い方

1. 「来訪を記録」で日程（年月日）、都道府県、理由を選び、登録します。
2. 1件の記録が1回の来訪になります。同じ日・同じ県への複数登録も可能です。
3. 「旅のマップ」の「得点 / 来訪回数」で、地図上の数字を切り替えます。合計得点・のべ来訪回数・訪問した都道府県数を同時に確認できます。
4. 地図の都道府県を選ぶと、両方の結果と理由別の内訳が開きます。「県名を表示」とズームにも対応しています。
5. 登録履歴から編集・削除ができ、結果はそのつど再計算されます。

## 点数の計算

参考画像の理由・点数を使用します。「未踏」は記録がない状態（0回・0点）として扱います。

| 来訪理由 | 1回あたりの点数 |
| --- | ---: |
| 単独、ラボセ | 1 |
| 大特典会 | 2 |
| 対バン、フェス | 3 |
| リリイベ | 4 |
| その他イベント | 5 |

**合計得点 = Σ（各来訪の理由の点数 × その都道府県が属する地方の倍率）**

例：東京都への単独1回・リリイベ2回なら、来訪回数は3回、基本点は `1 × 1 + 2 × 4 = 9点`。関東の倍率を1.5倍にすると13.5点となり、来訪回数は3回のままです。

倍率は初期値が全地方1倍で、設定から0〜100倍、小数第2位まで変更できます。理由ごとの集計と地方別集計も表示します。得点は小数第2位まで扱います。

## 地方区分

北海道、東北、関東、中部、近畿、中国、四国、九州・沖縄の8区分です。三重県は近畿、山梨県・長野県・新潟県は中部です。区分や理由の点数は `dist/data.js` に集約しています。

## 保存とバックアップ

- 記録は利用中のブラウザのlocalStorageに保存されます。サーバーへの個人の来訪記録の送信、アカウント登録、端末間同期はありません。
- ブラウザや端末を変更する場合は、設定の「書き出す」でJSONを保管し、移行先で「読み込む」を使ってください。
- 読み込みでは日程・都道府県・理由・倍率・ID重複を検証し、置き換え前に確認を表示します。
- ローカルプレビューと公開URLでは保存先が異なります。
- 画像保存は、選択中の「得点 / 来訪回数」を反映したPNGを生成します。
- 旧形式の回数のみのバックアップは、日程・理由不明の旧記録として保持し、1回＝1点に地方倍率を適用します。架空の日程や理由は生成しません。

## 開発

依存ライブラリのインストールやビルド変換は不要です。Node.js 20以上とPython 3を使います。

```sh
npm run dev
# http://127.0.0.1:4173

npm test
npm run build
```

Node.jsを使わず、`python3 -m http.server 4173 --directory dist --bind 127.0.0.1` でも起動できます。ES Modulesと地図の読み込みにHTTPを使うため、HTMLの直接起動（file://）には対応していません。

静的ホスティングの公開ディレクトリは `dist/` です。GitHub Pages等でも配置できます。

## 構成

- `dist/data.js` — 47都道府県・地方区分・理由ごとの点数
- `dist/model.js` — 来訪記録の検証、回数・得点の集計、バックアップ形式
- `dist/app.js` — フォーム、履歴、地図、ローカル保存、画像出力
- `dist/styles.css` — レスポンシブ表示
- `dist/assets/map-data.json` — 同梱SVGから生成した都道府県形状・ラベル位置
- `tests/model.test.js` — 理由別集計、倍率、編集・削除、日付検証、バックアップのテスト
- `.openai/hosting.json` — Sitesの静的配信設定

来訪記録（`id, date, prefectureId, reasonId`）と地方の倍率を分けて保存し、得点と回数を都度計算しています。倍率変更によって元の来訪記録が書き換わることはありません。

## 地図素材

地図は [lalamalink/japan-map-svg](https://github.com/lalamalink/japan-map-svg) のCC0素材を使用し、沖縄の配置・色・ラベルをアプリ用に調整しています。地図はディフォルメ表現です。測量用の正確な形状・距離ではありません。元の素材を `dist/assets/japan.svg` に同梱しています。

書体はGoogle FontsのNoto Sans JP / Noto Serif JPを読み込み、利用できない場合は端末の日本語フォントで表示します。アプリの機能は外部の地図APIやサーバーに依存しません。
