# たびのあと — 都道府県カウンター

日本地図から都道府県を選び、行った累計回数を登録するWebアプリです。スマートフォンとPCに対応し、結果を **得点 / 来訪回数** で切り替えられます。

## 登録と計算

1. 「来訪を記録」の「日本地図から選ぶ」を開き、都道府県をタップします。拡大・縮小、キーボード操作にも対応しています。
2. 選択した県の保存済み回数が表示されます。＋ / −、回数ボタン、数字の直接入力で累計回数を指定します。
3. 「回数を保存」で、その県の累計回数を更新します。同じ数字を何度保存しても重複加算しません。0回に戻すことも可能です。
4. 日付・来訪理由の登録はありません。
5. 都道府県ごとの一覧で、回数・得点を同時に確認できます。地方と訪問済み条件で絞り込めます。

**都道府県の得点 = 来訪回数 × その県が属する地方の倍率**

**合計得点 = 各都道府県の得点の合計**

例：東京都5回、大阪府2回で、関東1.5倍・近畿1倍なら、総来訪回数は7回、合計得点は `5 × 1.5 + 2 × 1 = 9.5点` です。

倍率は初期値が全地方1倍です。設定で0〜100倍、小数第2位まで変更でき、倍率を変えても回数は変わりません。来訪回数は0〜999,999回の整数です。

## 結果画面

- 地図の「得点 / 来訪回数」で数字を切り替えます。
- 合計得点・のべ来訪回数・訪問した都道府県数・地方別集計を表示します。
- 都道府県を選ぶと回数・得点・倍率の内訳を確認でき、回数の変更画面へ移動できます。
- 県名表示・ズーム・選択中の表示を反映したPNG画像の保存に対応します。

## 保存と以前の記録

- 記録はブラウザのlocalStorageに保存されます。アカウント登録、サーバーへの来訪記録の送信、端末間同期はありません。
- 機種変更・ブラウザ変更時は、設定からJSONを書き出し、移行先で読み込んでください。ローカルプレビューと公開URLは別の保存先です。
- バックアップ読み込みでは回数・都道府県・倍率を検証し、置き換え前に確認を表示します。
- **以前の日付・理由付き記録は、1件＝1回として県別の累計回数へ移行します。** 旧形式の回数も加算して保持します。得点は理由による点数を使わず、新しい「回数 × 地方倍率」で再計算します。
- 現行の保存・バックアップ形式は `version: 3` で、`counts`（県別累計回数）・`multipliers`（地方倍率）・更新情報のみを保存します。日付・理由を含む来訪イベントは保持しません。

## 地方区分

北海道、東北、関東、中部、近畿、中国、四国、九州・沖縄の8区分です。三重県は近畿、山梨県・長野県・新潟県は中部です。区分は `dist/data.js` に集約しています。

## 開発

依存ライブラリのインストールやビルド変換は不要です。Node.js 20以上とPython 3を使います。

```sh
npm run dev
# http://127.0.0.1:4173

npm test
npm run build
```

Node.jsを使わず、`python3 -m http.server 4173 --directory dist --bind 127.0.0.1` でも起動できます。ES Modulesと地図の読み込みにHTTPを使うため、HTMLの直接起動には対応していません。静的ホスティングの公開ディレクトリは `dist/` です。

## 構成

- `dist/data.js` — 47都道府県・地方区分・回数の範囲
- `dist/model.js` — 累計回数の設定、集計、バックアップと以前の記録の移行
- `dist/app.js` — 回数入力、地図選択、一覧、ローカル保存、画像出力
- `dist/styles.css` — レスポンシブ表示
- `dist/assets/map-data.json` — 同梱SVGから生成した都道府県形状・ラベル位置
- `tests/model.test.js` — 累計更新・倍率・ゼロ回・入力検証・移行・バックアップのテスト
- `.openai/hosting.json` — Sitesの静的配信設定

## 地図素材

地図は [lalamalink/japan-map-svg](https://github.com/lalamalink/japan-map-svg) のCC0素材を使用し、沖縄の配置・色・ラベルを調整しています。地図はディフォルメ表現です。元の素材を `dist/assets/japan.svg` に同梱しています。

書体はGoogle FontsのNoto Sans JP / Noto Serif JPを読み込み、利用できない場合は端末の日本語フォントで表示します。アプリの機能は外部の地図APIやサーバーに依存しません。
